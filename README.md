# RedPlay

Информационный портал по Lineage 2 Main, Essence и Special Project.

## Локальный запуск

```bash
pnpm install
pnpm dev
```

## Проверка production-сборки

```bash
pnpm build
pnpm start
```

Проект автоматически развёртывается в Vercel из ветки `main`.
