# Семантическое ядро RedPlay

Актуальная структура для `redplay.stream`. Ядро используется как редакционный план: запросы распределяются по страницам и публикациям, а не вставляются в текст списком.

## Главная страница

Основной запрос: `Lineage 2`.

Поддерживающие запросы:

- Lineage 2 новости
- Lineage 2 обновления
- Lineage 2 гайды
- Lineage 2 база знаний
- Lineage 2 патчноуты
- корейские обновления Lineage 2
- Lineage 2 Main
- Lineage 2 Essence
- Lineage 2 Special Project

Title: `Lineage 2 – новости, обновления, гайды и база знаний | RedPlay`.

## Версии игры

| Страница | Основной кластер | Дополнительные направления |
|---|---|---|
| `/lineage-2/main` | Lineage 2 Main | новости, обновления, гайды, классы, новые серверы Main |
| `/lineage-2/essence` | Lineage 2 Essence | Special Project, Wolf, Eva, обновления Essence, гайды Essence |

Essence и Special Project объединены на уровне контента. Различия внутри публикации отмечаются переключателем аудитории и отдельными блоками.

## Правила против конкуренции страниц

1. Один основной запрос закрепляется за одной страницей.
2. Страница категории отвечает на широкий запрос, статья – на конкретную тему.
3. Main и Essence не смешиваются в title, если материал относится только к одной версии.
4. Essence и Special Project объединяются в одной статье, когда механика общая; различия отмечаются внутри неё.
5. В title не повторяется RedPlay или название версии дважды.
6. В каждом материале должны быть один H1, содержательные H2/H3, краткий ответ в начале и ссылки на родительскую категорию.
7. Теги описывают реальные сущности статьи: класс, зона, предмет, патч или механику. Общие слова вроде `игра` и `новости` не используются как отдельные теги.
